Este documento registra a implantação não destrutiva dos oito domínios sobre a arquitetura já existente.

1. M1 Core — N01.
2. M2 Orquestração — N01.

8. M8 Governança/Memória — RegenerativeMemory, TemporalVectorDB, DecisionTrace, GovernanceBackend e proveniência.

## Regra de autoridade

O AETERNUM overlay não cria um segundo SARA, segundo ERU, segundo event bus, segunda memória ou segundo transporte. Os componentes existentes continuam proprietários de suas capacidades.

## Regra de prova

Estados externos são declarados como contrato federado/adaptador até existir uma conexão real. Infraestrutura pendente nunca é convertida em sucesso sintético.
